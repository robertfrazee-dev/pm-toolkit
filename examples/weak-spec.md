# Smart Substitutions

## Overview
Users sometimes can't find ingredients. We will use AI to suggest substitutions so they can still cook the recipe. This will make users happier and increase engagement.

## Solution
When a user views a recipe, each ingredient gets a "swap" button. Tapping it shows 3 AI-generated substitutes. The user picks one and the recipe updates, including quantities.

## Requirements
- Swap button on every ingredient
- AI suggestions should be fast and accurate
- Works for all recipes
- Should respect dietary preferences
